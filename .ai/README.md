# DocuBatch AI — AI Engineering Workspace

1. Copy this `.ai/` directory into the repository root.
2. Keep the skill and non-sensitive project documentation in Git.
3. Do not commit secrets, `.env`, uploaded files, private documents, or extracted personal data.
4. Run the initialization prompt from the project owner/AI assistant to generate complete indexes from the local checkout.
5. Update `CURRENT_TASK.md` at the end of each substantial coding session.

This is a documentation starter kit based on a partial review of the public repository, not a full source-code audit.
